# IntelliJ Installation

## Concept

Kotlin มาจาก JetBrains และ IntelliJ ก็เป็น IDE ของบริษัทเดียวกัน IDE คือโปรแกรมที่ใช้พิมพ์โค้ด พร้อมเครื่องมือ debug, ชี้ปัญหา และรันด้วยคลิกเดียว

พิมพ์ Kotlin ใน text editor ธรรมดาก็ได้ แต่การ compile เป็นไฟล์ที่เครื่องรันได้ต้องทำเองทั้งหมด IDE รับงานนั้นไป เหลือให้โฟกัสที่โค้ด และใส่ syntax highlighting ให้อ่านง่ายขึ้น

## Example

บทนี้เป็นขั้นตอนติดตั้ง ไม่มี syntax ให้เทียบกับ Java

1. เปิดเว็บ JetBrains แล้วโหลด IntelliJ ลิงก์อยู่ในคำอธิบายวิดีโอ
2. Ultimate เป็นเวอร์ชันเสียเงิน Community ฟรี และพอสำหรับคลิปนี้
3. ติดตั้งแล้วเปิดโปรแกรม ขั้นถัดไปคือสร้างโปรเจกต์
