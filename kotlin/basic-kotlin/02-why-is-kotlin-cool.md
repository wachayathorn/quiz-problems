# Why is Kotlin cool?

ที่มา: Philipp Lackner — Full 2025 Kotlin Crash Course For Beginners (`dzUc9vrsldM`) · 01:30–03:57

## Concept

Philipp ให้เหตุผลสามข้อว่าทำไมเขาชอบ Kotlin

**Interoperability กับ Java** — Java ถูกใช้กว้างมาก โดยเฉพาะโปรเจกต์องค์กรใหญ่ และรันได้หลายแพลตฟอร์ม Kotlin แปลลงไปเป็น bytecode ชุดเดียวกับ Java ตอนรัน เครื่องไม่รู้ว่าต้นทางเขียนด้วยภาษาไหน จึงผสมโค้ด Java กับ Kotlin ในโปรเจกต์เดียวกันได้ และเรียกไลบรารี Java ที่มีอยู่แล้วได้

**Syntactic sugar** — ทางลัดที่ทำให้ทำเรื่องเดิมได้ด้วยโค้ดสั้นลง

**ภาษาเอนกประสงค์** — ใช้ได้หลายทาง

- Native Android เป็นภาษาหลักของงานที่เขาทำ
- Kotlin Multiplatform จาก JetBrains เขียนชุดเดียวแล้วไป desktop, iOS, Android และ web
- Backend มีเฟรมเวิร์กของ Kotlin ชื่อ Ktor ตอนอัดคลิปเขายังมองว่า Ktor ยังไม่แพร่ในอุตสาหกรรมมาก แม้เขาจะใช้แล้วและชอบ
- Spring Boot เป็นเฟรมเวิร์ก backend ของ Java ที่โตและใช้กันกว้างกว่า เพราะ Kotlin เรียก Java ได้ทั้งก้อน จึงเขียน Spring Boot ทั้งโปรเจกต์ด้วย Kotlin ได้ ถ้าจะทำ backend เขาแนะนำให้ดู Spring Boot คู่กับ Kotlin
